# Typography and Tone of Voice

Guide for choosing typography and establishing tone of voice.

## Typography by Product Personality

| Personality | Suggested Category | Notes |
|---|---|---|
| Corporate / B2B | Geometric or neutral sans-serif (Inter, Helvetica) | Regular/Medium/Bold weights |
| Warm / Consumer | Rounded sans-serif (Nunito, Quicksand) | Lighter weights by default |
| Technical / Dev Tool | Monospace accents + neutral sans-serif | Monospace for code/names |
| Calm / Mindfulness | Soft, lightweight sans-serif | Generous line-height |

## Modular Type Scale

| Token | Size | Typical Usage |
|---|---|---|
| `text-xs` | 12px | Auxiliary text |
| `text-sm` | 14px | Secondary text |
| `text-base` | 16px | Body text |
| `text-lg` | 18px | Subheadings |
| `text-xl` | 24px | Section titles |
| `text-2xl` | 32px | Main headers |
| `text-3xl` | 48px | Hero banners |

## Defining Tone of Voice

1. Choose 3-4 descriptive adjectives (e.g., Direct, Trustworthy, Approachable).
2. Write 2-3 concrete copy examples (error message, call-to-action, empty state).
3. Specify explicit anti-patterns (e.g., "avoid corporate buzzwords like synergy").

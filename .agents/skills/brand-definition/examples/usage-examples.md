# Brand Definition Usage Examples

## Example 1 — B2B Tech Startup (Fluxa)
- Tone: Direct, trustworthy, concise.
- Palette: Cool & Professional (Primary `#0066CC`, Accent `#00B4D8`).
- Contrast Check: `#FFFFFF` over `#0066CC` → 5.1:1 (Passes AA).
- Typography: Inter (sans-serif).

## Example 2 — Mindfulness App (Respira)
- Tone: Calm, approachable, gentle.
- Palette: Forest Theme (Primary `#2D6A4F`, Accent `#52B788`).
- Contrast Check: `#FFFFFF` over `#2D6A4F` → 5.2:1 (Passes AA & AAA).
- Typography: Rounded sans-serif.

## Example 3 — Open Source Dev Tool
- Tone: Technical, direct, developer-focused.
- Palette: Vibrant (Primary `#7928CA`, Accent `#FF0080`).
- Typography: Sans-serif body with monospace code accents.

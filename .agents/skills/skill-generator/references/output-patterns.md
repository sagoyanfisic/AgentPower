# Output Patterns

Use these patterns to ensure consistent, high-quality skill outputs.

## Template Pattern

Provide templates for expected outputs.

### Strict Requirements (API responses / spec files):
```markdown
## Report Structure
ALWAYS follow this exact template structure:
# [Report Title]
## Executive Summary
## Key Findings
## Recommendations
```

### Flexible Guidelines:
```markdown
## Report Structure
Suggested default structure (adapt based on findings):
# [Report Title]
## Summary
## Findings
## Recommendations
```

## Example Pattern

Provide input/output pairs for quality guidance:

```markdown
Input: User login implementation
Output: feat(auth): add JWT-based user authentication
```

# Enfoque según la tarea

Usa el modelo de la sesión de Codex. Esta plantilla no cambia modelos ni requiere subagentes.

| Tipo | Enfoque |
| --- | --- |
| Lectura o explicación | Consultar solo el contexto pertinente |
| Cambio acotado | Implementar y verificar el comportamiento afectado |
| Arquitectura o requisitos | Registrar decisiones, restricciones y alternativas |
| Revisión | Leer cambios y reportar hallazgos sin modificar archivos |

Si una tarea mezcla tipos, organiza el plan por resultados verificables. La clasificación
de `scripts/pick_model.py` es orientativa y no autoriza acciones adicionales.

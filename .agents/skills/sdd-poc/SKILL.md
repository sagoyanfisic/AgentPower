# sdd-poc

Lee el contexto del proyecto y `../poc-strategy/SKILL.md`. Define hipótesis, alternativas pertinentes y criterios medibles antes de experimentar.
Aísla el trabajo en `poc/nombre/` o un directorio temporal. Limita el experimento al alcance autorizado; no integres código experimental automáticamente en la app.
Ejecuta y registra las mediciones reales. Entrega un informe de resultados, límites y recomendación. Si una decisión se acuerda, actualiza la especificación correspondiente. No presentes una recomendación como una decisión ya confirmada.
